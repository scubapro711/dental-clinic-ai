## 📝 Document Naming Convention

All documentation follows this naming pattern:

```
<TOPIC>_<TYPE>_<VERSION>.md

Examples:
- PHASE_3_MASTER_PLAN_V2.md
- SAAS_PRICING_REVISED_GCP_ILS.md
- ACCESSIBILITY_IMPLEMENTATION_V20.8.0.md
```

**Types:**
- PLAN - Planning documents
- ANALYSIS - Analysis and audits
- STRATEGY - Strategic documents
- COMPLETE - Completion reports
- SUMMARY - Summary documents
- GUIDE - How-to guides

## 🔄 Document Lifecycle

1. **Draft** - Initial creation

3. **Final** - Approved and versioned
4. **Archive** - Moved to archive/ (if outdated)
