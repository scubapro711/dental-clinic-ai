## מבוא

### מי היא שרה?

שרה היא עוזרת קלינית דיגיטלית המיועדת לסייע לרופאי שיניים בניהול הטיפול הקליני במטופלים. היא מחוברת ישירות למערכת Odoo Dental ויכולה לבצע מגוון רחב של משימות קליניות.

### למה שרה שונה מאלכס?

| היבט | אלכס (קבלה) | שרה (קלינית) |
|------|------------|--------------|
| **תפקיד** | קבלה ושירות לקוחות | עוזרת קלינית |
| **גישה** | מטופלים וצוות | רופאים בלבד |
| **תחום** | תורים, חשבוניות, שאלות כלליות | תרשימי שיניים, טיפולים, מרשמים |
| **רמת גישה** | מידע בסיסי | מידע רפואי מלא |

## יכולות שרה

### 1. ניהול תרשים שיניים (אודונטוגרמה)

שרה יכולה:
- להציג תרשים שיניים מלא של מטופל
- לעדכן סטטוס של שן ספציפית
- לתעד טיפולים שבוצעו
- להציג היסטוריית טיפולים לפי שן

**דוגמה:**
```
אתה: "הצג לי את תרשים השיניים של דוד כהן"
שרה: "הנה תרשים השיניים של דוד כהן. רואה שיש 3 סתימות קיימות..."

אתה: "עדכן שן 16 לסטטוס filled"
שרה: "עדכנתי את שן 16 לסטטוס 'filled'. התיעוד נשמר במערכת."
```

### 2. ניהול מרשמים ותרופות

שרה יכולה:
- להציג מרשמים קיימים של מטופל
- ליצור מרשם חדש
- לחפש תרופות במאגר
- לבדוק אינטראקציות תרופתיות

**דוגמה:**
```
אתה: "אני צריך ליצור מרשם לדוד כהן"
שרה: "בטח. קודם בדקתי - אין לו אלרגיות ידועות לתרופות. איזו תרופה תרצה לרשום?"

אתה: "אמוקסיצילין 500 מ"ג"
שרה: "מצאתי את התרופה. כמה פעמים ביום וכמה ימים?"

אתה: "3 פעמים ביום, 7 ימים"
שרה: "מרשם נוצר בהצלחה. המטופל יכול לקבל אותו בבית המרקחת."
```

### 3. היסטוריה רפואית ואלרגיות

שרה יכולה:
- להציג היסטוריה רפואית מלאה
- לתעד אלרגיות חדשות
- להציג מצבים כרוניים
- להתריע על סיכונים פוטנציאליים

**דוגמה:**
```
אתה: "הצג היסטוריה רפואית של שרה לוי"
שרה: "שרה לוי - היסטוריה רפואית:
- אלרגיות: פניצילין (חומרה: severe)
- מצבים כרוניים: סוכרת סוג 2
- תרופות שוטפות: מטפורמין 500 מ"ג

⚠️ שים לב: בגלל האלרגיה לפניצילין, אל תרשום אמוקסיצילין!"
```

### 4. תכנון טיפולים

שרה יכולה:
- להציג תוכניות טיפול קיימות
- ליצור תוכנית טיפול חדשה
- להעריך עלויות
- לתעדף טיפולים

**דוגמה:**
```
אתה: "צור תוכנית טיפול למשה אברהם"
שרה: "בטח. מה שם התוכנית?"

אתה: "שיקום מקיף"
שרה: "אוקיי. אילו טיפולים תרצה לכלול?"

אתה: "סתימה בשן 16, טיפול שורש בשן 26, כתר בשן 36"
שרה: "תוכנית הטיפול נוצרה. הערכת עלות כוללת: 8,500 ₪"
```

## איך להשתמש בשרה

### גישה לשרה

1. **דרך הדשבורד הקליני:**
   - היכנס למערכת עם חשבון רופא
   - לחץ על "דשבורד קליני"
   - שרה תופיע בצד ימין

2. **דרך פרופיל מטופל:**
   - פתח פרופיל מטופל
   - לחץ על לשונית "עוזרת קלינית"
   - שרה תהיה מודעת להקשר המטופל

### ממשק המשתמש

```
┌─────────────────────────────────────────┐
│  שרה - עוזרת קלינית        מטופל: דוד  │
├─────────────────────────────────────────┤
│  פעולות מהירות:                         │
│  [תרשים] [מרשמים] [היסטוריה] [תוכנית] │
├─────────────────────────────────────────┤
│                                         │
│  💬 שיחה עם שרה                         │
│                                         │
│  שרה: שלום! איך אני יכולה לעזור?       │
│                                         │
│  אתה: הצג תרשים שיניים                 │
│                                         │
│  שרה: הנה התרשים...                     │
│                                         │
├─────────────────────────────────────────┤
│  [הקלד הודעה...]              [שלח]    │
└─────────────────────────────────────────┘
```

### פעולות מהירות

לחיצה על כפתור פעולה מהירה תמלא אוטומטית את השדה עם הפקודה המתאימה:

- **תרשים שיניים** → "הצג לי את תרשים השיניים של [מטופל]"
- **היסטוריית טיפולים** → "הצג היסטוריית טיפולים של [מטופל]"
- **יצירת מרשם** → "אני צריך ליצור מרשם ל[מטופל]"
- **היסטוריה רפואית** → "הצג היסטוריה רפואית של [מטופל]"

## תסריטים נפוצים

### תסריט 1: ביצוע סתימה

```
1. בחר מטופל מחיפוש
2. שאל שרה: "הצג תרשים שיניים"
3. זהה שן עם cavity
4. בצע את הטיפול
5. עדכן שרה: "עדכן שן 16 לסטטוס filled"
6. תעד: "צור רשומת טיפול - סתימה בשן 16, עלות 500 ₪"
```

### תסריט 2: מטופל חדש - בדיקה ראשונית

```
1. שאל שרה: "הצג היסטוריה רפואית של [מטופל]"
2. בדוק אלרגיות ומצבים כרוניים
3. בצע בדיקה קלינית
4. תעד ממצאים: "עדכן שן 11 לסטטוס cavity"
5. צור תוכנית טיפול: "צור תוכנית טיפול - סתימה בשן 11"
```

### תסריט 3: טיפול שורש + כתר

```
1. שאל שרה: "הצג תוכנית טיפול של [מטופל]"
2. בצע טיפול שורש
3. תעד: "צור רשומת טיפול - טיפול שורש בשן 26"
4. עדכן: "עדכן שן 26 לסטטוס root_canal"
5. רשום מרשם: "צור מרשם - אמוקסיצילין + אדוויל"
6. תזמן המשך: "תזמן תור להתקנת כתר בעוד שבועיים"
```

### תסריט 4: מטופל עם אלרגיה

```
1. שאל שרה: "הצג היסטוריה רפואית"
2. שרה מתריעה: "⚠️ אלרגיה לפניצילין!"
3. התאם טיפול: "חפש תרופה אנטיביוטית חלופית"
4. שרה מציעה: "אזיתרומיצין או קלינדמיצין"
5. רשום מרשם מותאם
```

## פקודות מהירות

### תרשים שיניים

```
"הצג תרשים שיניים של [מטופל]"
"עדכן שן [מספר] לסטטוס [סטטוס]"
"מה הסטטוס של שן [מספר]?"
```

**סטטוסים נפוצים:**
- `healthy` - בריא
- `cavity` - עששת
- `filled` - סתום
- `crown` - כתר
- `root_canal` - טיפול שורש
- `missing` - חסר
- `implant` - שתל

### טיפולים

```
"הצג היסטוריית טיפולים של [מטופל]"
"צור רשומת טיפול - [סוג טיפול] בשן [מספר]"
"מה הטיפול האחרון שבוצע?"
```

### מרשמים

```
"הצג מרשמים של [מטופל]"
"צור מרשם - [תרופה] [מינון]"
"חפש תרופה [שם תרופה]"
"יש אינטראקציה בין [תרופה1] ל[תרופה2]?"
```

### היסטוריה רפואית

```
"הצג היסטוריה רפואית של [מטופל]"
"הוסף אלרגיה - [אלרגן]"
"הוסף מצב כרוני - [מחלה]"
"מה התרופות השוטפות?"
```

### תוכניות טיפול

```
"הצג תוכניות טיפול של [מטופל]"
"צור תוכנית טיפול - [שם]"
"מה העלות המשוערת?"
```

## שיטות עבודה מומלצות

### ✅ DO - כן לעשות

1. **תמיד בדוק היסטוריה רפואית לפני טיפול**
   ```
   "הצג היסטוריה רפואית של [מטופל]"
   ```

2. **תעד כל טיפול מיד אחרי ביצועו**
   ```
   "צור רשומת טיפול - סתימה בשן 16, עלות 500 ₪"
   ```

3. **עדכן תרשים שיניים אחרי כל שינוי**
   ```
   "עדכן שן 16 לסטטוס filled"
   ```

4. **השתמש בפעולות מהירות לחיסכון בזמן**
   - לחץ על כפתור במקום להקליד

5. **בדוק אלרגיות לפני מרשם**
   - שרה תתריע אוטומטית אם יש בעיה

### ❌ DON'T - לא לעשות

1. **לא לדלג על בדיקת היסטוריה רפואית**
   - זה סיכון בטיחותי!

2. **לא לשכוח לתעד טיפולים**
   - חשוב לתיעוד משפטי וביטוחי

3. **לא להסתמך על זיכרון**
   - תמיד בדוק במערכת

4. **לא לרשום מרשם בלי לבדוק אינטראקציות**
   - שרה תעזור לך לזהות בעיות

## פתרון בעיות

### שרה לא עונה

**בעיה:** שרה לא מגיבה להודעות

**פתרון:**
1. בדוק חיבור לאינטרנט
2. רענן את הדף (F5)
3. התנתק והתחבר מחדש
4. פנה לתמיכה טכנית

### שרה אומרת "אין גישה"

**בעיה:** "מצטערת, אין לך הרשאה לפעולה זו"

**פתרון:**
1. וודא שאתה מחובר כרופא (לא כמטופל)
2. בדוק שיש לך הרשאות קליניות
3. פנה למנהל המערכת

### מידע לא מעודכן

**בעיה:** שרה מציגה מידע ישן

**פתרון:**
1. בקש מחדש: "רענן את המידע"
2. בדוק ב-Odoo ישירות
3. סנכרן מחדש את המערכת

### שרה לא מבינה שאלה

**בעיה:** שרה לא מצליחה לבצע פקודה

**פתרון:**
1. נסח מחדש בצורה פשוטה יותר
2. השתמש בפעולות מהירות
3. פרק לשאלות קטנות יותר

**דוגמה:**
```
❌ "תן לי סיכום מקיף של כל הטיפולים והמרשמים של דוד כהן מהשנה האחרונה"

✅ "הצג היסטוריית טיפולים של דוד כהן"
   "הצג מרשמים של דוד כהן"
```

## תמיכה ויצירת קשר

### שאלות נפוצות

**ש: האם שרה יכולה להחליף את המזכירה?**  
ת: לא. שרה היא עוזרת קלינית לרופאים בלבד. אלכס מטפל בקבלה ושירות לקוחות.

**ש: האם המטופלים יכולים לדבר עם שרה?**  
ת: לא. שרה נגישה רק לרופאים וצוות קליני עם הרשאות מתאימות.

**ש: האם שרה שומרת היסטוריה של השיחות?**  
ת: כן. כל שיחה נשמרת למעקב ותיעוד.

**ש: האם אפשר להדפיס מידע משרה?**  
ת: כן. השתמש בכפתור "הדפס" או העתק את הטקסט.

### דיווח על בעיות

אם נתקלת בבעיה:
1. צלם מסך (Screenshot)
2. תעד מה ניסית לעשות
3. שלח ל: support@dentaflow.ai
4. או פתח ticket במערכת התמיכה
