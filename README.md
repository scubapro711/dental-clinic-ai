## 🏗️ Architecture

### Tech Stack
- **Backend:** FastAPI, Python 3.11, LangGraph, PostgreSQL
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS
- **AI:** OpenAI GPT-4, LangChain, LangGraph
- **Database:** PostgreSQL (Cloud SQL), Redis (caching)
- **Infrastructure:** Google Cloud Run, Cloud Build, Cloud SQL
- **Monitoring:** Sentry, OpenTelemetry, Google Cloud Trace
- **ERP:** Odoo 17 (21 models integrated)

### Key Features
- ✅ 5 AI Agents with LangGraph orchestration
- ✅ PostgresSaver for conversation memory
- ✅ Odoo Integration (3,185 lines, 21 models)
- ✅ HIPAA Compliance (Harper agent)
- ✅ Multi-tenant architecture
- ✅ RBAC enforcement
- ✅ Sentry error tracking
- ✅ OpenTelemetry tracing
- ✅ JWT authentication with organization context
- ✅ 30+ specialized agent tools
