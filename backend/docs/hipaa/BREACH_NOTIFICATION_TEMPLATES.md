## 1. Overview

This document provides standardized templates for breach notifications as required by HIPAA regulations (45 CFR § 164.400-414). All templates are bilingual (Hebrew/English) to serve Israeli dental clinics.

**Notification Requirements:**
- **To Covered Entity:** Within 60 days of discovery
- **To Individuals:** Within 60 days (Covered Entity's responsibility)
- **To HHS:** Within 60 days if 500+ individuals affected
- **To Media:** Immediately if 500+ individuals in same jurisdiction

## 7. Notification Workflow

### 7.1 Decision Tree

```
Incident Detected
    ↓
Is PHI involved?
    ↓ YES                    ↓ NO
Risk Assessment         Document & Close
    ↓
Is it a Breach?
    ↓ YES                    ↓ NO
How many affected?      Document & Monitor
    ↓
< 500 individuals       ≥ 500 individuals
    ↓                        ↓
- Notify Covered Entity  - Notify Covered Entity
- Log for annual report  - Notify HHS (60 days)
- Covered Entity         - Media notification
  notifies individuals   - Covered Entity
  (60 days)               notifies individuals
                          (60 days)
```

### 7.2 Timeline

| Day | Action |
|-----|--------|
| **Day 0** | Incident discovered |
| **Day 1** | Initial assessment, containment |
| **Day 2-7** | Investigation, root cause analysis |
| **Day 7-14** | Breach determination, risk assessment |
| **Day 14-30** | Prepare notifications, affected list |
| **Day 30-60** | Send notifications (deadline: Day 60) |
| **Day 60+** | Post-incident review, improvements |
