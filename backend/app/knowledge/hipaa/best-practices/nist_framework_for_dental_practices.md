> # NIST Cybersecurity Framework for Dental Practices
> 
> This document provides guidance on how dental practices can use the National Institute of Standards and Technology (NIST) Cybersecurity Framework to improve their cybersecurity posture and comply with the HIPAA Security Rule.
> 
> ## What is the NIST Cybersecurity Framework?
> 
> The NIST Cybersecurity Framework is a voluntary framework that consists of standards, guidelines, and best practices to manage cybersecurity risk. It is designed to be flexible and adaptable to organizations of all sizes and sectors. The Framework is organized into five core functions: [1]
> 
> *   **Identify:** Develop an organizational understanding to manage cybersecurity risk to systems, assets, data, and capabilities.
> *   **Protect:** Develop and implement the appropriate safeguards to ensure delivery of critical infrastructure services.
> *   **Detect:** Develop and implement the appropriate activities to identify the occurrence of a cybersecurity event.
> *   **Respond:** Develop and implement the appropriate activities to take action regarding a detected cybersecurity event.
> *   **Recover:** Develop and implement the appropriate activities to maintain plans for resilience and to restore any capabilities or services that were impaired due to a cybersecurity event.
> 
> ## How Can Dental Practices Use the NIST Framework?
> 
> Dental practices can use the NIST Cybersecurity Framework to:
> 
> *   **Conduct a risk assessment:** The Framework can be used to identify and assess cybersecurity risks to ePHI.
> *   **Develop and implement a risk management plan:** The Framework can be used to develop and implement a plan to mitigate identified risks.
> *   **Comply with the HIPAA Security Rule:** The Framework can be used to demonstrate compliance with the HIPAA Security Rule's administrative, physical, and technical safeguards.
> 
> ## Mapping the NIST Framework to the HIPAA Security Rule
> 
> The following table maps the NIST Cybersecurity Framework's five core functions to the HIPAA Security Rule's safeguards:
> 
> | NIST Framework Function | HIPAA Security Rule Safeguard |
> |---|---|
> | **Identify** | Risk Analysis and Management (164.308(a)(1)) |
> | **Protect** | Access Control (164.312(a)), Security Awareness and Training (164.308(a)(5)), Device and Media Controls (164.310(d)(1)) |
> | **Detect** | Audit Controls (164.312(b)), Security Incident Procedures (164.308(a)(6)) |
> | **Respond** | Response and Reporting (164.308(a)(6)) |
> | **Recover** | Contingency Plan (164.308(a)(7)) |
>
