# HIPAA Technical Safeguards FAQ

This document answers common questions about the Technical Safeguards of the HIPAA Security Rule.

**1. What are the Technical Safeguards?**

The Technical Safeguards are a set of standards in the HIPAA Security Rule that govern the technology and the policies and procedures for its use to protect electronic protected health information (ePHI) and control access to it.

**2. What are the five standards of the Technical Safeguards?**

The five standards are:

*   **Access Control:** Limiting access to ePHI to only authorized individuals.
*   **Audit Controls:** Implementing hardware, software, and/or procedural mechanisms that record and examine activity in information systems that contain or use ePHI.
*   **Integrity:** Policies and procedures to protect ePHI from improper alteration or destruction.
*   **Person or Entity Authentication:** Procedures to verify that a person or entity seeking access to ePHI is the one claimed.
*   **Transmission Security:** Technical security measures to guard against unauthorized access to ePHI that is being transmitted over an electronic communications network.

**3. Is encryption mandatory under the Security Rule?**

Encryption is not mandatory, but it is an "addressable" implementation specification. This means that a covered entity must implement encryption if it is a reasonable and appropriate safeguard in its security analysis. If not, the covered entity must document why it would not be reasonable and appropriate and implement an equivalent alternative measure if reasonable and appropriate.

**4. Does the Security Rule allow for sending e-PHI in an email or over the Internet?**

Yes, the Security Rule allows for e-PHI to be sent via email or over the internet, but it must be done securely. The transmission must be protected by appropriate safeguards, such as encryption.

**5. Do the Security Rule requirements for access control apply to employees who telecommute?**

Yes, the Security Rule’s access control requirements apply to all employees, including those who telecommute. A covered entity must have policies and procedures in place to control access to ePHI, regardless of where the employee is located.
